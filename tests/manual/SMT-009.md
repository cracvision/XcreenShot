# Editar texto de la imagen

ID: SMT-009.

## Visto en la instancia de desarrollo (2026-11-14)

- Pruebas automáticas:
  - `xs-capture` `edit_the_text_of_a_button`: en un botón azul con "Enviar" en blanco, Editar texto deja el botón azul sin restos de las letras y un objeto Texto "Enviar" blanco (ΔE ≤ 5) del tamaño original; se reescribe como cualquier texto; dos Deshacer devuelven la imagen idéntica píxel a píxel; una selección que corta la palabra avisa; sin texto, "No se encontró texto para editar".
  - `letter_size_from_the_letters`: el tamaño de letra según la altura de sus píxeles y qué letras tiene.
  - UI: el aviso de la selección cortada, Ajustar la selección al texto, Editar así, Cancelar; desde el menú de una redacción, con su lugar ajustado a las líneas.
- En la instancia aislada, con una ventana de ajustes generada: el botón azul "Aceptar" pasa a "Guardar" en blanco sin restos del texto anterior; una selección que corta una línea responde con `cut` y el rectángulo ajustado.

## Para Carlos (en la próxima caminata)

1. [ ] Captura un botón con texto (por ejemplo, uno azul con letras blancas) > herramienta **Selección** sobre el texto > clic derecho > **Editar texto**. El texto desaparece del botón, aparece un texto editable igual con el cursor al final; escribe otra palabra.
2. [ ] Comprueba que el color y el tamaño se parecen al original.
3. [ ] **Deshacer**: la imagen queda como estaba.
4. [ ] Selecciona media palabra > Editar texto: aparece el aviso con **Ajustar la selección al texto**.
5. [ ] Con la Redacción automática abierta, clic derecho en una redacción > **Editar texto**: se quita la redacción y el texto de debajo queda editable.
6. [ ] Sobre un degradado o una foto: el aviso dice que pueden quedar marcas.
