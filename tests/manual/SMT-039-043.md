Vía A: la app le pregunta a Claude con la clave de cada uno (SMT-039 a SMT-042). Vía B: Claude Desktop o Claude Code se conectan a XcreenShot por MCP (SMT-043, con las herramientas de APP-029).

Pruebas automáticas:
- `crates/xs-ai/src/tests.rs`, contra un servidor local que imita la API (ninguna petición sale del equipo; la clave queda en memoria):
  - la IA viene desactivada y solo la ventana de Preferencias la activa;
  - sin clave no se envía nada;
  - la clave solo se guarda desde la ventana y se muestra por sus cuatro últimos caracteres;
  - preguntar envía la imagen del documento (PNG) con la petición, las cabeceras de la API y el respaldo del servidor (`fallbacks: "default"`), y la respuesta llega por partes con sus tokens;
  - el seguimiento lleva la conversación anterior; Haiku va sin respaldo;
  - los errores (clave, saturado, sin saldo, rechazo, sin conexión) llegan con un motivo claro;
  - **Detener** corta la respuesta, y mientras hay una petición en curso otra responde `busy`;
  - los nombres sugeridos salen como nombres de archivo válidos;
  - **Probar la clave** no envía imágenes;
  - las imágenes de más de 2576 px se reducen;
  - preguntar no toca el archivo del documento.
- `crates/xs-editor/src/tests.rs`: renombrar mantiene carpeta y extensión, no pisa otro archivo, acepta un cambio solo de mayúsculas y lo guardado después va al archivo nuevo. `document.image` da la imagen final en PNG reducida.
- `crates/xs-library/src/lib.rs`: limpieza de nombres de archivo (caracteres no válidos, nombres reservados de Windows).
- `crates/xs-cli/src/mcp.rs` y `crates/xs-cli/tests/cli.rs`: `xcreenshot mcp` responde JSON-RPC, lista las herramientas (sin `ai_*`), entrega las imágenes como imagen MCP y, con la app cerrada, devuelve un error de herramienta.
- `app/src/editor/aiState.test.ts`: la respuesta en curso muestra siempre el último texto, aunque un evento llegue dos veces.

## Tanda A · IA dentro de la app — Carlos

Necesitas una **clave de la API de Claude** con saldo:
1. Entra en `platform.claude.com` con tu cuenta.
2. En **Billing**, añade saldo; con 5 USD tienes para cientos de preguntas.
3. En **API keys**, pulsa **Create key** y cópiala.

Costo aproximado de cada petición:
- con Opus 5.5, una pregunta sobre una captura cuesta unos 2 a 4 centavos de dólar;
- con Haiku 5.5, un nombre cuesta menos de una décima de centavo.

1. [ ] **Preferencias > IA**: la IA está desactivada. Actívala: aparece un aviso con qué se envía, a quién y el costo. Prueba **Cancelar** (sigue desactivada) y después **Activar**.
2. [ ] Pega tu clave en **Clave de API** y pulsa **Guardar**: queda "Guardada (termina en ····xxxx)". Pulsa **Probar la clave**: "La clave funciona con Claude Opus 5.5".
3. [ ] Abre una captura en el editor. Menú **IA > Preguntar a la IA…** > **Describir** > **Enviar**: la descripción aparece mientras se escribe, en español, y al final se ven los tokens.
4. [ ] Escribe "un poema para…" con los detalles que la imagen no dice y pulsa **Enviar**. Después, **Insertar en la imagen**: el poema queda como texto editable. `Ctrl+Z` lo quita.
5. [ ] Escribe "hazlo más corto" y envíalo: la IA recuerda el poema anterior.
6. [ ] Pide algo largo ("describe con mucho detalle cada elemento") y pulsa **Detener** a mitad: queda lo recibido, con "(detenido)".
7. [ ] Menú **IA > Sugerir nombre…**: llega un nombre que describe la captura. **Otra sugerencia** da otro. **Renombrar** cambia el nombre del archivo en `Documentos\XcreenShot\2026-11`.
8. [ ] **Ayuda > Abrir registros**: en el archivo de hoy aparece "cloud AI request done" con el modelo y los tokens, pero ninguna palabra de las respuestas ni la clave.

## Tanda B · Desde Claude Desktop o Claude Code — Carlos

No necesita la clave de la tanda A ni tener la IA activada.

1. [ ] **Preferencias > IA > Copiar la configuración**.
2. [ ] En Claude Desktop, abre **Settings > Developer > Edit Config**, pega el bloque y reinicia Claude Desktop. Si el archivo ya tiene servidores, añade la entrada `xcreenshot` dentro de `mcpServers`.
3. [ ] En un chat nuevo de Claude Desktop, XcreenShot aparece entre las herramientas.
4. [ ] Con una captura abierta en XcreenShot, pide "Describe la captura que tengo abierta en XcreenShot": Claude pide permiso para usar `document_image` y la describe.
5. [ ] Pide "Ponle un nombre descriptivo": Claude usa `document_rename` y el archivo cambia de nombre.
6. [ ] (Opcional, Claude Code) **Copiar el comando para Claude Code**, pégalo en una terminal, y `claude mcp list` muestra `xcreenshot`.
