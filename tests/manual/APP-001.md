# APP-001 · Proceso en segundo plano e instancia única

Plataformas: Windows 11 y macOS. Compilación: `npm run tauri dev` (en `app/`) o instalada.

- [ ] Cierra todas las ventanas. El ícono sigue visible y el atajo de prueba (`Ctrl+Alt+Shift+K` / `⌃⌥⇧K`) muestra la notificación "XcreenShot funciona".
- [ ] Con la app en marcha, ábrela otra vez (menú Inicio / Launchpad o `target/debug/xcreenshot-app`). No aparece un segundo proceso ni un segundo ícono, y se muestra la ventana principal.
- [ ] Con dos usuarios con sesión abierta a la vez (cambio rápido de usuario), el atajo de uno no afecta a la sesión del otro.
- [ ] (M1) Doble clic en un `.xshot` lo abre en el editor existente en ≤ 1 s.
