# APP-024 · Permisos de macOS y Reparar permisos

Solo macOS. Para Cámara y Micrófono hace falta la app empaquetada (`npm run tauri build`), porque el sistema exige los textos de `Info.plist`.

- [ ] Preferencias > General > Permisos lista Grabación de pantalla, Accesibilidad, Cámara y Micrófono con su estado (Concedido / Denegado / Sin pedir).
- [ ] **Pedir** en Grabación de pantalla muestra la solicitud del sistema; **Abrir Ajustes del Sistema** abre la página exacta.
- [ ] Retira el permiso en Ajustes del Sistema y vuelve a XcreenShot: el bloque lo muestra denegado sin reiniciar y el ícono muestra el punto de atención.
- [ ] (M6, firma estable) Tras actualizar la app, los permisos siguen concedidos.
- [ ] (M1) El atajo Capturar sin permiso muestra el aviso con Reparar permisos y no crea imagen; la captura continúa al conceder el permiso.
