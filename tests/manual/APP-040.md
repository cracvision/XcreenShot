# APP-040 · Requisitos del sistema

- [ ] La prueba de humo (`xcreenshot app ping`, ventana principal, Preferencias, atajo de prueba) pasa en Windows 10 22H2, Windows 11 x64, Windows 11 ARM64, macOS 14 y el macOS más reciente.
- [ ] En macOS 13 el sistema indica que la app no es compatible (el paquete declara macOS 14.0 como mínimo), en lugar de cerrarse sin explicación.
- [ ] En un Windows anterior a 10 22H2 (compilación < 19045), la app muestra "XcreenShot necesita Windows 10 22H2 o posterior" y no arranca.
