# APP-012 · Tema de la interfaz

- [ ] Con Tema = Sistema, cambia el sistema de claro a oscuro: todas las ventanas abiertas cambian en ≤ 1 s, incluida la barra de título.
- [ ] Con Tema = Oscuro y el sistema en claro: ventana principal, Preferencias y diálogos se ven oscuros.
- [ ] Con una herramienta de contraste sobre capturas de ambas ventanas, el texto normal tiene ≥ 4,5:1 en ambos temas.
- [ ] Con el alto contraste del sistema activo se usan los colores del sistema.
