# Barra de edición rápida (M2, entrega 6) · EDT-006

Pruebas con la app en marcha (instancia aislada), 2026-11-12, Windows 11:
- [x] Al elegir una flecha aparece la barra con color, grosor, punta, tipo de línea, Estilos ▾ y ⋯; cambiar el grosor a 12 en la barra cambia la flecha (un paso de Deshacer).

## Para Carlos (cuando haya instalador)

1. [ ] Dibuja una flecha y elígela: encima aparece la barra. Cambia el color: cambian la flecha y Propiedades.
2. [ ] Pon un texto pegado al borde de arriba del lienzo y elígelo: la barra sale debajo.
3. [ ] Prueba la barra con un globo, una forma, un paso y un desenfoque.
4. [ ] **Estilos ▾** aplica un estilo guardado; **⋯** abre Propiedades.
5. [ ] En Preferencias > Editor desactiva **Barra de edición rápida**: no aparece con ningún objeto.
