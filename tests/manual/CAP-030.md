## Para Carlos (en la próxima caminata)

1. [ ] `Ctrl+Alt+Shift+M` (o Panel > Imagen > Selección = **Selector de ventanas**): aparecen todas tus ventanas, también las tapadas. Pasa el puntero y haz clic en una: sale entera, a tamaño real.
2. [ ] Escribe parte de un título: quedan solo las que coinciden. Muévete con las flechas y pulsa `Enter`.

4. [ ] `Esc` cierra el selector sin captura.
