# Ventanas como objetos · CAP-029

Visto en la instancia de desarrollo (2026-11-13, madrugada): `capture.fullscreen --windows true` con seis ventanas visibles dio un documento de 5120 × 2160 con seis objetos de imagen, cada uno con el nombre de su app y en la posición de su ventana.

## Para Carlos (en la próxima caminata)

1. [ ] Abre tres ventanas que se solapen. Panel > Imagen > Selección = Pantalla completa > marca **Cada ventana como un objeto** > Capturar.
2. [ ] En el editor hay un objeto de imagen por ventana; selecciónalos: cada uno es una ventana entera.
3. [ ] Borra el objeto de la ventana de delante: se ve completa la que estaba detrás.
4. [ ] Pega el portapapeles en Paint: es igual que una pantalla completa normal.
