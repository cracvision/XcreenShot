# APP-035 · Configuración administrada

Necesitas permisos de administrador para escribir en `C:\ProgramData\XcreenShot`. **Al terminar, borra el archivo** para que XcreenShot vuelva a ser normal.

1. Crea `C:\ProgramData\XcreenShot\managed.json` con:
   ```json
   {
     "version": 1,
     "locked": { "capture.autoDetect": false },
     "defaults": { "general.language": "es" },
     "policy": { "disableVideoCapture": true, "hideExperimental": true, "disabledDestinations": ["lan"] }
   }
   ```
2. Cierra XcreenShot del todo y ábrelo.
   - Esperado: Preferencias no tiene las secciones **Video** ni **Funciones en prueba**; el panel de captura no tiene la pestaña **Video**; en Preferencias > Captura, "Detección automática" sale con candado.
   - En una terminal: `xcreenshot settings set capture.autoDetect true` falla (código 6) y `xcreenshot record start` falla con `disabled_by_policy`.
   - Compartir (en el editor) no tiene **Red local…**.
3. Preferencias > Avanzado > **Configuración administrada** > **Ver**: la ruta, la fecha y lo bloqueado.
4. Rompe el archivo (borra una coma), reinicia XcreenShot.
   - Esperado: arranca; Avanzado dice "el archivo tiene errores" y Ver muestra la línea del error.
5. Borra el archivo y reinicia: todo vuelve a ser como antes.
