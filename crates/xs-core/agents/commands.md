# Command notes for AGENTS.md (APP-033)

`xcreenshot agents-md` builds AGENTS.md from the command registry and these notes: the
registry gives every command, its parameters and its flags; a row here adds the
example and the longer explanation. A command without a row still appears, with its
one-line description from `locales/en.json`. A row for a command that no longer
exists fails a test.

| ID | Example | What it does |
|---|---|---|
| `app.ping` | `xcreenshot app ping` | Version, platform, architecture, state, whether automation is on, UI language. |
| `app.commands` | `xcreenshot app commands --json` | Every command with JSON Schemas for params and result, scopes, and flags (`mutates`, `network`, `destructive`, `interactive`). |
| `app.show` | `xcreenshot app show` | Shows the main window. |
